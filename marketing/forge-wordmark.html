Putting Forge next to bolt

The two you kept from the first round are at the top. Below them, the same idea organised properly: three type directions, each run through an identical set of six colour treatments, so nothing is being compared against a moving target. Use the controls above to change the ground and the size.

forge
A

Gradient

White into brand blue across the word. Forge reads as the new thing without a divider or a badge doing the work. One caveat worth deciding on: the gradient has very little room to travel at navbar size — see the 24px row below.

Forge
B

Cormorant italic

A warmer, editorial Forge against the mark’s hard geometry — the contrast is the idea. Note it’s off-system today: Cormorant is our blog and pull-quote face, so adopting it here makes it a brand face too.

Three directions

Three type directions — sans, serif, and twenty-five experimental faces — each run through the same six blue ramps. Because the set is identical in all three, reading down compares faces and reading across compares colour.

Prototype page — not linked from anywhere and marked noindex. The bolt mark is images/bolt-logo.svg, inlined as a symbol and recoloured with currentColor so it follows the ground. “Forge” is live text (Inter for the gradient, Cormorant Garamond for the italic) rather than outlines, so either can be re-set without redrawing anything. The eighteen cut variations are in git history at b26a3e3 if any need to come back.
