Putting Forge next to bolt

The two you kept from the first round are at the top. Below them, the same idea organised properly: the two directions that survived review, each run through an identical set of six ramps, so nothing is compared against a moving target. Use the controls above to change the ground and the size.

forge
A

Gradient

White into brand blue across the word. Forge reads as the new thing without a divider or a badge doing the work. One caveat worth deciding on: the gradient has very little room to travel at navbar size — see the 24px row below.

Forge
B

Cormorant italic

A warmer, editorial Forge against the mark’s hard geometry — the contrast is the idea. Note it’s off-system today: Cormorant is our blog and pull-quote face, so adopting it here makes it a brand face too.

Sans, serif, and twenty more faces

Two type directions — the sans and the serif you kept — each run through the same six blue ramps, so the ramp is the only thing changing within a category and the face is the only thing changing between them. Because the set is identical in all three, reading down compares faces and reading across compares colour.

The bolt mark is images/bolt-logo.svg, inlined as a symbol and recoloured with currentColor so it follows the ground. “Forge” is live text (Inter for the gradient, Cormorant Garamond for the italic) rather than outlines, so either can be re-set without redrawing anything.
