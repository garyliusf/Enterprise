Why we bet on building in the browser

The case for an instant, zero-setup dev environment.

Alex Rivera Apr 14, 2026 8 min

Every developer knows the friction of a fresh machine: install the runtime, the package manager, the right versions, the editor extensions. Setup is where momentum goes to die.

The best dev environment is the one you never have to set up.

By running everything in the browser, Bolt.new removes that first hour of yak-shaving entirely. You open a tab and you are already building.
